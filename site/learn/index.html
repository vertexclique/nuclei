Learn Nuclei

From the first line in Cargo.toml to a server in production. Each chapter takes one idea, explains it, and shows it in a program you can run.

Nuclei is a proactive async runtime for Rust. A task hands its IO to the driver and gets the result back completed, and every core runs a shard of its own: its tasks, its timers, its buffers and its driver. These chapters teach it from the ground up and cover every way of using it that the crate offers.

Every example runs

Each program on these pages was compiled and run on Linux, on io_uring and on epoll, before it was published. The ones that need Unix (Unix sockets, Unix signals, Unix programs such as sort) say so.

Where to start

  • New to async runtimes: read the chapters in order. Setup, Runtime and Tasks are the core; Proactive IO explains what makes Nuclei different.
  • Moving from a readiness-based runtime: start with Migrate, then read Tasks and Proactive IO. The two behaviours that differ most are what dropping a task handle does and when a write is done.
  • Looking for one function: the API reference is on docs.rs.
