Setup

Add Nuclei to a project, choose its features, run a first program and see which kernel interface it picked.

What you need

Rust 1.99 or later. Nuclei itself is written in the 2024 edition; your crate may use any edition.

It builds for these systems, each on its own kernel interface:

SystemBackend
Linux, Androidio_uring where the kernel (6.1 or later) and the sandbox allow it, else epoll
illumosepoll
macOS, iOS, FreeBSD, NetBSD, OpenBSD, DragonFlykqueue
WindowsI/O completion ports

Any other target stops the build with Target OS is not supported.

A first program

#[nuclei::main] runs the async main on the runtime, and nuclei::spawn places a task on one of its shards; awaiting the task gives its output. There is nothing to set up: the first spawn or block_on starts the default runtime, with one worker shard per core the process may run on.

Features

FeatureDefaultWhat it gives
iouringonThe io_uring driver, on Linux and Android. Without it those systems run on epoll.
epollonNames epoll beside iouring. Epoll is built on Linux either way.
attributeson#[nuclei::main], #[nuclei::test] and #[nuclei::bench], from the nuclei-macros crate.
recycleoffNode memory for the lock-free queues, maps and channels the runtime is built on, from a per-thread cache over a slab layer instead of the global allocator.

recycle is for applications. Cargo turns a feature on for every user of a crate in the build, so a library that enabled it would enable it for all of them.

Which backend it runs on

With nothing set, Nuclei takes io_uring where the kernel lets this process make the ring its shards use, and the platform’s poller otherwise. It probes io_uring safely, even under a seccomp filter that kills a process for calling io_uring_setup. The NUCLEI_BACKEND environment variable picks one by hand: auto, io_uring or epoll on Linux, kqueue on macOS and the BSDs, iocp on Windows.

A backend named by hand that the process cannot have is an error with the reason, never a silent fallback. Backends has the details, and Errors the messages.
