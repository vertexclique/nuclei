Sync

Locks, semaphores, events, once-cells, cancellation and channels whose waits are futures, usable under any executor.

Futures and wakers, nothing else

Every wait in nuclei::sync is a future built from futures and wakers alone. A task that waits for a lock yields its shard instead of blocking the thread, and the same types work under any executor. Each primitive also has try_ forms that never wait, and blocking_ forms for plain threads. Called inside a Nuclei task, a blocking_ method runs a nested block_on, so the shard keeps running its other tasks.

Mutex, RwLock, Semaphore, Notify, Barrier, OnceCell, SetOnce and the mpsc, oneshot, broadcast and watch channels take the names, signatures, error types and documented behaviour of the established async sync API, so code written against that API compiles against these. Nuclei adds Event, Latch, Lazy, the upgradable read of the RwLock, reentrant locks keyed by an Owner, OnceCell::get_or_init_racy and CancellationToken.

Dropping a pending wait withdraws its waiter, and anything handed to it in the meantime is passed on, so no wakeup is lost. (A Barrier wait is the one exception: an arrival that was counted stays counted.)

Locks

  • Mutex: lock().await, try_lock, blocking_lock, and lock_owned on an Arc<Mutex> for a guard that is 'static.
  • RwLock: read, write and upgradable_read, with owned and try_ forms; with_max_readers caps the readers.
  • ReentrantMutex and ReentrantRwLock: locks a holder may take again, keyed by an Owner token rather than a thread, because a task can move between threads and many tasks can share one.

Semaphores, notifications, events, latches, barriers

  • Semaphore: acquire and acquire_many give a permit that returns itself when dropped; close makes every wait fail.
  • Notify: notified().await waits; notify_one wakes one waiter (or the next one to come), notify_waiters wakes all that wait now.
  • Event: set once, wait forever after. Latch: opens when count_down brings its count to zero.
  • Barrier: releases its waiters in groups of n; one waiter of each group is the leader.

Once-cells and lazy values

OnceCell::get_or_init runs an async initializer once while other callers wait for it; get_or_init_racy never waits: callers that race all build with a synchronous initializer, one value is published and the rest are dropped. SetOnce is set once, and readers can wait until it is. Lazy builds its value on first access (Lazy::force).

Channels

ChannelShapeNote
mpsc::channel(n)many senders, one receiver, at most n queueda send waits for room: backpressure
mpsc::unbounded_channel()many senders, one receiversend never waits and is a plain function
oneshot::channel()one value, one sender, one receiverthe receiver is the future; an error if the sender is dropped
broadcast::channel(n)many senders, many receiverskeeps the last n values, rounded up to a power of two; a receiver that falls behind gets Lagged
watch::channel(init)many senders, many receiverskeeps only the latest value; changed waits for one not seen yet

A channel closes once every sender is gone: the receiver takes what is left, then gets None (an error, for oneshot, broadcast and watch). What one sender sends comes out in the order it was sent.

Cancellation tokens

A CancellationToken is a shutdown signal shared by many tasks. child_token makes a token that is cancelled with its parent (and can be cancelled alone); cancelled().await waits for it; run_until_cancelled(future) runs a future and gives None if the token is cancelled first; drop_guard cancels it when the guard goes.
