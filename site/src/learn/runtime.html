The attribute

#[nuclei::main] turns an async main into a program: its body runs in block_on on the default runtime. It may return anything main may, such as std::io::Result<()>. Its options, comma separated:

  • threads = N: a runtime of its own with N workers; 0 runs every task on the thread inside block_on.
  • start_paused = true: a runtime of its own whose clock starts paused (see Time).
  • builder = "path": a runtime of its own, built from the Builder the function at path returns; threads and start_paused, when given, apply on top of it.
  • crate = "path": where the crate is, for code that re-exports it.
2 worker shards

With builder, every setting comes from a function of your own:

block_on

nuclei::block_on runs a future to its end on the calling thread. The first call, or the first spawn, starts the default runtime, so a plain fn main needs nothing else. (nuclei::drive is the same call under the name earlier versions used.)

block_on nests

block_on works anywhere, inside a task too. There it nests: the shard keeps running its other tasks, timers and IO until the future completes, so synchronous code deep in a call stack can wait on a future without holding the shard.

Two rules come with it. The task that called block_on is not polled again until the call returns, so a future that waits for that very task never completes. And each level runs on the thread's stack, so the depth is bounded by max_nesting; one level more panics with a message that says so.

A block_on of another runtime nests the same way. The shard's loop keeps running under the shard's own runtime, so its tasks still spawn onto it and read its clock; only the nested future runs under the other one. A task that a runtime with no worker (worker_threads(0)) spawns there, inside its nested block_on or under its enter() guard, runs with that runtime current at every poll and as it is dropped.

A runtime of your own

Runtime::new() starts one with every setting at its default; Runtime::builder() sets them (every setting). A runtime spawns, runs block_on and runs blocking work, as the free functions do on the default runtime.

Dropping a Runtime stops its workers, drops the tasks they still hold, and waits for the threads to exit: every one but a thread still blocked in a poll its shard was taken from (Tasks), and the dropping thread itself when a task of the runtime drops it. A worker a task starts meanwhile is stopped and waited for as well, and none starts once the drop took its threads. Bytes that dropped handles wrote behind still go out, each for at most write_behind_linger; one still under way when the drop is done carries on on the linger thread, one for the process. shutdown_timeout bounds the whole wait, and returns early only once every thread it waits for has exited; shutdown_background does not wait at all.

With no worker taking tasks (worker_threads(0)), what a dropped handle wrote behind goes out on the linger thread too, counted by its runtime so a drop waits for it: never on the dropping thread's own shard, which runs only at that thread's next block_on.

build checks every setting first: a value no runtime can work with, or two that do not fit together, fails with InvalidInput naming the setting, its value and what it must be (Errors).

Handles and entering

runtime.handle() gives a RuntimeHandle: cheap to clone, usable from any thread to spawn on that runtime or to block_on. A handle does not keep its runtime running.

  • RuntimeHandle::current(): the runtime this thread is inside, or the default one.
  • RuntimeHandle::try_current(): the runtime this thread is inside, or an error; it never starts the default one.
  • runtime.enter(): makes the free functions (spawn, spawn_blocking, ...) use this runtime on this thread until the guard drops.
  • id(): a RuntimeId, different for every runtime of the process.

Choosing the worker

spawn picks the shard for you. To pick it yourself, name the worker: indices run from 0 to workers(), and worker_index() says which one the calling code runs on.

  • spawn_on_worker(k, future) places a task on worker k, where it stays for its whole life: a handoff moves the worker's shard to another thread with its tasks, and worker_index() still answers k.
  • spawn_local_on_worker(k, make) runs make on worker k and spawns the future it makes there, so the future need not be Send.
  • on_each_worker(make) does that once on every worker that takes tasks and gives a JoinSet with one task per worker: a listener per core, a cache per core, a mesh of channels between them.
  • task::Builder::worker(k) places a task spawned with options the same way.

A worker the runtime does not have, or one that stopped, refuses the task with InvalidInput; a task it took is never dropped unrun.

A value per worker

shard_local! declares a static, a ShardLocal, that holds one value per worker, made on its first use there: a counter, a cache or a buffer that the worker's tasks share without a lock. The value lives in the worker's shard, not in its thread, so it moves with the shard on a handoff and the worker's tasks always see the same one.

with runs a closure on this worker's value, and the shard stays on the thread while it runs: keep the closure short. Only code on a worker reaches one: off the workers (in block_on's own thread, on the blocking pool, on another thread) try_with answers a ShardAccessError and with panics. Code whose poll lost the shard to a handoff still reaches the value: each with there borrows the shard back from the thread that runs it now, for the length of the call.

The values go when their worker stops, once its IO is settled. A value that panics as it is dropped is logged at error, and the worker's other values and its going go on.

The default runtime, configured

The free functions use the runtime the calling thread is inside, or else the default runtime. To configure the default one, build it with build_global before anything starts it.

build_global fails with the default runtime is already running once a free function, the attribute or an earlier build_global started it: call it first thing in main.
